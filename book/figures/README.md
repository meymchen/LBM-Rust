# 插图维护指南

本目录保存技术文档的手写 Typst 图源。概念示意图与生成的数据图必须分开维护：前者解释关系和过程，后者展示可追溯的程序输出。

## 目录约定

- `components.typ`：全书共享的颜色、分面标题和说明组件；
- `fluid-foundations.typ`：流体基础章节的概念示意图；
- `lbm-foundations.typ`：LBM 基础章节的概念示意图；
- `diffusion-practice.typ`：扩散问题实践章节的概念示意图与章首抽象插图；
- `../assets/generated`：由 Rust 程序确定性生成的 CSV 和 SVG，不手工编辑。数据图使用 Kuva 绘制，生成器再补充文档级 SVG 标题和描述。
- `../assets/benchmarks`：版本化的性能参考运行，包含 CSV、SVG 和运行元数据。计时结果不参加确定性资产对比；更新时必须保留硬件、工具链、问题规模和统计方法。

## 图形语法

概念示意图使用固定版本的 CeTZ 0.4.2 绘制。首次构建时 Typst 会下载并缓存该包。不得为了避免依赖而退回字符箭头、手工空格定位或卡片式流程图。

- 格点使用实心轮廓圆，格子连接使用浅色细线；
- 离散速度使用固定长度箭头，离散分布函数的大小使用柱长或面积表达；
- 蓝色表示迁移或输运，橙色表示碰撞，深灰色表示静止或边界；
- 颜色必须与文字、形状或线型共同编码信息，不能成为唯一线索；
- 时间和过程默认从左到右排列；
- 图中标签使用中文，变量、数学符号和代码标识保持原样。
- 图中文字不得小于 `8.5pt`，技术箭头必须使用统一线宽和箭头尺寸的矢量路径。

## 数据图

运行以下命令更新生成资产：

```sh
make regenerate
make check-generated
make figure-check
```

普通的 `make pdf` 只读取已有资产，不运行数值程序。数据图必须标明输入参数、单位和生成程序；柱状图从零基线开始，坐标范围不得夸大差异。展示性观察不能写成验证结论。性能图还必须记录硬件、工具链、问题规模和统计方法。

## 新增插图检查清单

- 图只回答一个主要教学问题；
- 正文在图前说明阅读目的，在图后给出结论和适用边界；
- 图中没有正文尚未定义的符号；
- A4 正常字号和彩色、灰度输出均清楚可读；
- 数据、索引、离散速度和权重来自可追溯的单一事实来源；
- `make check` 通过；
- 人工审阅确认图没有造成新的物理误解。
