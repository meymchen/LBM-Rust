# 分离定量分析与可视化

项目将出版级数据图、空间场交换、交互式后处理和定量验证分成不同边界：Kuva 生成静态数据图，vtkio 将均匀笛卡尔格子的场快照写成 VTK XML ImageData，ParaView 用于场探索和可复现的后处理流程，而定量验证指标由 Rust 按明确的离散定义计算。Kuva 当前缺少文档级 SVG 可访问元数据和通用的字节确定性保证，因此项目以受控后处理补充根级标题、描述和 ARIA 属性，并用自己的语义测试与生成资产检查约束结果。二维扩散是首个真实后处理目标：它已经由真实求解器产生可验证的场快照，并且足以验证运行目录、运行元数据和时间序列工具链；二维通道流仍是首个流动后处理目标。在真实求解器就绪前建立的确定性合成场继续作为格式互操作夹具保留。该分层避免把 ParaView 的插值结果误作数值真值，也避免为尚不存在的非结构格子需求过早设计通用交换模型。
